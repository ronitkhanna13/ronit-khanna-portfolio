# Ronit Khanna — Portfolio

A responsive personal portfolio covering analytics, research, projects, professional experience, leadership, community contributions, education, and achievements.

**Live website:** https://ronit-khanna-portfolio.netlify.app/

## Features

- Project filters for analytics, research, and product work
- Accessible project detail dialogs
- Professional experience timeline
- Community contributions, awards, education, and skills
- Responsive desktop and mobile layouts
- Contact, LinkedIn, GitHub, and BruinConnect links

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — page structure and static content
- `style.css` — responsive styles
- `app.js` — project content, filters, and dialogs
- `netlify.toml` — static hosting configuration

## Deployment

The current Netlify site was deployed manually. To enable automatic deployments, connect this repository to that existing Netlify project with the publish directory set to `.` and no build command.

## Content

Portfolio content is based on the owner's expanded resume. Project illustrations are illustrative visuals rather than screenshots; the NFL chart reflects the baseline and model accuracy figures supplied in the resume. No patient data is included.

Google Fonts supplies DM Sans and Manrope; local font fallbacks are defined.
